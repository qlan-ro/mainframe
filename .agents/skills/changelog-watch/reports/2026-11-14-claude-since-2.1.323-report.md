# changelog-watch: claude 2.1.323 → 2.1.325 (2026-11-14)

Entries seen: 139 · risks: 0 · opportunities: 1 · relevant, no action: 27 · dropped as irrelevant: 111

There is no 2.1.324 section upstream, so the delta is one version. Nothing breaks a consumed surface. Most of the relevant entries tighten when the CLI asks for permission: Bash compound commands, sandboxed Bash, read-only git outside the project, and artifact publishes visible outside the org. That changes how often `can_use_tool` fires, not its shape.

Two entries bear on the open 2.1.323 high risk: CLIProxy chats assume a 1M window and stop compacting in time. That risk is not fixed on `main`: no `CLAUDE_CODE_DISABLE_1M_CONTEXT` or `CLAUDE_CODE_MAX_CONTEXT_TOKENS` anywhere in `packages/core-rs/crates`. One 2.1.325 fix makes gateway sessions compact on a context-length error instead of failing every turn. That softens the symptom but does not fix the gauge or the late compaction. The other entry widens `CLAUDE_CODE_MAX_CONTEXT_TOKENS`, which may give the pending fix a per-model option (see the opportunity below).

I checked the `applyFlagSettings` refusal against the 2.1.318 binary, which is the installed CLI. Flag settings merge across calls (`{...prev, ...settings}`). Mainframe's payload is three booleans plus `effortLevel`, and the settings schema `.catch`es a bad `effortLevel` to `undefined` instead of failing. So Mainframe's payload cannot trigger the new refusal. Nothing was run live.

## Adoption opportunities

- **Per-model context window for CLIProxy chats** ("Changed `CLAUDE_CODE_MAX_CONTEXT_TOKENS` to also set the context window of unrecognized model IDs that start with `claude-`, such as a gateway's `claude-sonnet-latest`"). The wording implies the variable already sets the window for unrecognized IDs without that prefix, which covers every CLIProxy model. The fix drafted for the 2.1.323 high risk sets `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` and drops all proxy chats to 200K. Setting this variable instead, from a per-model window table, would let a 400K model compact at 400K. The proxy publishes no window (`ProxyModel.context_window: None`), so the table would be hand-kept. Lands in `src/cliproxy.rs::resolve_env`. Size: small. Before adopting, verify live that the variable applies to a non-`claude-` ID.
