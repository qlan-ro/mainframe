Codex's Default permission mode now asks before every edit and every command, matching what "Interactive" already promises in the permission menu — it used to edit and run commands unprompted, the same real privilege as Accept Edits. Existing Codex chats left in Default mode will start seeing approval prompts; pick Accept Edits for the old auto-edit behavior. This also lets a Claude chat in Default mode delegate to a Codex chat, since both now carry the same real privilege.
