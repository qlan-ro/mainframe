Fork a chat from any sent user message. Hover the message and choose "Fork from here": a new chat opens beside the parent with the conversation up to that message, and the message's text waits unsent in its composer. The parent is untouched, and a turn still running in the parent doesn't block the fork. Files are not rolled back. The button is disabled, with the reason, on a chat's first message and wherever the whole-chat Fork can't run.
