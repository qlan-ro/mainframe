A chat an agent started names the chat that started it in its hover card, and a chat with delegated tasks shows a chip in its header listing them with live status. The `delegate_task` tool call renders as a card with the child chat's title, status, and an open link. Messages another agent queued for a busy chat appear above the composer until delivered, and each can be cancelled.
