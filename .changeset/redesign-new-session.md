A new session opens on its project: where it will run, the three sessions you used last, and open tasks to start from. Picking a task adds it to the message under anything you typed. Files, images, preview captures and code annotations sit in the composer as tiles of one size, with notes you edit in place. Captures and the editor's “Add Agent Context” now join the message you are writing instead of being sent or quoted at once, and quotes say which message they are from. If a send fails, its draft returns above newer edits. When the target changes, context from the previous workspace stays in the draft until you include it or switch back.
