Surface the Setup Advisor in the toolbar. Opening it fingerprints the active project and lists the MCP servers, skills, hooks, subagents, and plugins that its stack earns, one tab per category, each command a click away from the clipboard. Every recommendation shows the signal that triggered it, and a third-party rule names its source repo and install count in a distinct chip — an aggregator install stays a decision, not a surprise.
