# Codex CLI consumed-surface checklist

Source of truth: `packages/core-rs/crates/mainframe-adapter-codex/`. Every
notification and result shape the crate deserializes is declared as a typed
struct in `src/types.rs`/`src/item_types.rs` — unlike the Claude crate,
serde does the shape-checking here. That makes drift *quieter*, not safer: a
struct that fails to deserialize is logged and dropped by the caller
(`if let Ok(p) = serde_json::from_value(...) { ... }`), so a renamed field
degrades exactly like an unrecognized Claude event, just one layer further
from the wire. The crate ships **no fixture directory** — every test in
`tests/` builds its JSON-RPC payloads inline — so "add a regression test"
recommendations below must name a test file and the payload to pin, not just
say "add coverage".

See `docs/research/adapters/README.md` for the row schema, ID grammar, and citation
rules.
