# @qlan-ro/mainframe-types

## 2.8.0

### Minor Changes

- [#772](https://github.com/qlan-ro/mainframe/pull/772) [`1bea6f0`](https://github.com/qlan-ro/mainframe/commit/1bea6f060be230257a163787e290a98c34e59f8c) Thanks [@doruchiulan](https://github.com/doruchiulan)! - Fork a chat from any sent user message. Hover the message and choose "Fork from here": a new chat opens beside the parent with the conversation up to that message, and the message's text waits unsent in its composer. The parent is untouched, and a turn still running in the parent doesn't block the fork. Files are not rolled back. The button is disabled, with the reason, on a chat's first message and wherever the whole-chat Fork can't run.

- [#772](https://github.com/qlan-ro/mainframe/pull/772) [`1bea6f0`](https://github.com/qlan-ro/mainframe/commit/1bea6f060be230257a163787e290a98c34e59f8c) Thanks [@doruchiulan](https://github.com/doruchiulan)! - Agents can now see and drive other Mainframe chats. Every Claude and Codex chat gets a `mainframe` MCP server with tools to list, read, and wait on chats, launch new ones, send or steer messages, interrupt a turn, and delegate a task to a child chat whose result comes back as a message once the parent is idle. Stopping a chat also stops the work it delegated. Messages another agent wrote now appear as cards naming the sending chat instead of as your own messages.

- [#772](https://github.com/qlan-ro/mainframe/pull/772) [`1bea6f0`](https://github.com/qlan-ro/mainframe/commit/1bea6f060be230257a163787e290a98c34e59f8c) Thanks [@doruchiulan](https://github.com/doruchiulan)! - A chat an agent started names the chat that started it in its hover card, and a chat with delegated tasks shows a chip in its header listing them with live status. The `delegate_task` tool call renders as a card with the child chat's title, status, and an open link. Messages another agent queued for a busy chat appear above the composer until delivered, and each can be cancelled.

- [#772](https://github.com/qlan-ro/mainframe/pull/772) [`1bea6f0`](https://github.com/qlan-ro/mainframe/commit/1bea6f060be230257a163787e290a98c34e59f8c) Thanks [@doruchiulan](https://github.com/doruchiulan)! - A chat an agent delegated a task to now lives inside its parent's `delegate_task` card instead of the sidebar. Expanding the card shows the task chat's latest messages as they stream, with a link to open the full chat. When the task needs your permission or an answer, the card opens itself and you answer right there; the parent shows as waiting while any task below it does, and the push notification opens the parent. Task chats no longer appear in the sidebar, the archived list, or search, except one whose parent was deleted.

- [#772](https://github.com/qlan-ro/mainframe/pull/772) [`1bea6f0`](https://github.com/qlan-ro/mainframe/commit/1bea6f060be230257a163787e290a98c34e59f8c) Thanks [@doruchiulan](https://github.com/doruchiulan)! - Switch a chat between Claude and Codex without starting a new chat. After the first message, the provider tabs in the model menu show each provider's models; picking one asks to continue the chat there. The new provider gets a budgeted, verbatim selection of the chat's history with your next message, and going back to a provider that already ran in the chat resumes its earlier session with what happened since. A divider marks each switch in the thread. Switching is unavailable while a turn runs, while messages are queued, while background work is running, and in temporary or side chats; the tabs say why.
