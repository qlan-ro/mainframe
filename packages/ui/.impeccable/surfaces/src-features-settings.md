# Settings & dialogs

## General

- **Open links in** offers Workspace and Browser. Workspace opens web links in a workspace browser tab. Browser uses the system browser. File links open in the workspace editor.
- **Finished work** replaces Transcript’s Verbose and Compact options. Fold closes eligible finished work rows in the transcript. Keep open leaves their steps visible. A stored Verbose choice becomes Keep open. Compact becomes Fold.
